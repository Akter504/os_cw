Было разработано приложение на языке C++, позволяющее
 выполнять операции над коллекциями данных заданного типа и
 контекстами их хранения ( по сути СУБД ).
 Коллекции данных однозначно идентифицируются следующим
 набором строковых параметров:
* название пула схем данных, хранящего схемы данных;
* название схемы данных, хранящей коллекции данных;
* название коллекции данных

1) Реализовано выполнение команд, вводимых пользователем в
 интерактивном диалоге с возможностью выполнения команд из файла.
 2) Реализован механизм персистетности, позволяющий выполнять
 запросы к данным в рамках коллекции данных на заданный момент времени, при помощи поведенческих паттернов проектирования
 «Команда», «Цепочка обязанностей». 
4) Обеспечено хранение объектов строк, размещённых в объектах данных, основе структурного паттерна проектирования
 «Приспособленец». Доступ к строковому пулу обеспечен на основе порождающего паттерна «Одиночка».
 5) Реализован, для режима in memory cache, механизм сохранения
 состояния системы хранения данных в файловую систему и механизм
 восстановления состояния системы хранения данных из файловой
 системы.
 7) Реализована возможность кастомизации (для заданной коллекции
 данных) аллокаторов для размещения объектов данных: аллокатор на
 глобальной куче, аллокатор с дескрипторами границ. Для последнего кастомизируется метод
 выделения памяти: первый, лучший, худший подходящий.
 15) Реализовано серверное приложение, собирающее
 логи клиентской и серверной части приложения в файловые потоки
 вывода. Конфигурирование серверного логгера обеспечивается на основе
 файла со структурой JSON
